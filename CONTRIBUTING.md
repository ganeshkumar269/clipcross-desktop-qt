# Contributing to this project 

Thank you for considering contributing to this project! We welcome contributions from everyone, whether it's reporting issues, submitting pull requests, or improving the documentation. By following these guidelines, you'll help us make the contribution process easy and effective for everyone involved.

## Setting up the Project
### Prerequisites
* install qt 6.5 (https://www.qt.io/download-qt-installer-oss)

clone the project in your local and use it with your favourite IDE (Intellij Clion recommended)
